# Security policy

SailTune holds the access token to your music server, so I take reports
seriously. Please don't open a public issue for a security problem.

## Reporting a vulnerability

[Report it privately on GitHub](https://github.com/tordenskjoldsw/harbour-sailtune/security/advisories/new).

Include the SailTune version (shown on the About page), the Sailfish OS
version, the server and its version, the steps to reproduce and what an
attacker gains. Use a test server or Jellyfin's public demo server: never
send me a real password, a real access token or the address of your own
server.

I confirm that your report arrived, keep you posted while I work on a fix,
and credit you in the release notes unless you would rather stay anonymous.

## Supported versions

Only the latest release gets security fixes. The
[security review of October 2026](docs/security-review-2026-10.md) lists
what was checked and fixed before the first release.
